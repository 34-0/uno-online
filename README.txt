طريقة التشغيل الصحيحة:
1. ثبّت Node.js على الكمبيوتر.
2. شغّل ملف "تشغيل_اللعبة.bat".
3. ستفتح اللعبة تلقائياً على http://localhost:3000
4. أنشئ غرفة وأرسل رمز الغرفة.

للعب مع أصدقائك على نفس شبكة Wi‑Fi:
- شغّل اللعبة على جهاز المضيف.
- اعرف عنوان IPv4 للجهاز (مثلاً 192.168.1.5).
- افتح عند الأصدقاء: http://192.168.1.5:3000
- اسمح لـ Node.js في Windows Firewall إذا ظهر تنبيه.

للعب من خارج الشبكة/من أي مكان:
- يجب رفع المشروع على استضافة تدعم Node.js وWebSocket.
- المشروع جاهز للنشر؛ استخدم npm install ثم npm start.
- لا تفتح index.html مباشرة، لأن ذلك لن يشغل خادم الأونلاين.

ملاحظة: الغرف محفوظة في الذاكرة مؤقتاً وتختفي عند إيقاف الخادم.
