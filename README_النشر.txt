هذه النسخة مجهزة للنشر العام.

النشر على Render:
1) أنشئ حساباً في Render.
2) ارفع هذا المجلد إلى مستودع GitHub.
3) في Render اختر New > Blueprint أو Web Service.
4) اختر المستودع.
5) Render سيستخدم Dockerfile تلقائياً.
6) بعد النشر سيعطيك رابطاً عاماً مثل:
   https://uno-online-xxxx.onrender.com

لا تفتح index.html مباشرة. الموقع العام يعمل عبر server.js وWebSocket.

مهم:
- الخادم يحفظ الغرف في الذاكرة فقط؛ عند إعادة تشغيل الخادم تنتهي الغرف.
- اللعبة حالياً بدون تسجيل حسابات وقاعدة بيانات.
